# 林锋手帐 · 自动推送 v2.0.2（标准扩展版）

本版改用酒馆自带的 `/api/search/visit` 网页读取接口，由你现有的酒馆服务器请求公开网页。只安装普通前端扩展并刷新即可，不再要求另装Node服务器插件，不必修改config.yaml或重启VPS进程。

## 更新与安装

1. 解压“标准扩展Git仓库包”，把下面6个文件全部放在插件仓库根目录，不要再套文件夹。
2. 已安装旧版：在酒馆“扩展”中更新该仓库，然后刷新整个酒馆页面。首次安装：在“扩展→安装扩展”粘贴仓库HTTPS地址，装好后刷新。
3. 扩展设置中的“林锋手帐·自动推送”应显示“酒馆联网接口已连接·v2.0.2”。
4. 为修复普通网页被过滤、补齐真实错误提示，把配套修复包里的 `notebook.json` 覆盖到原手帐GitCode/GitHub仓库，原酒馆助手加载器点“立刻拉取最新手帐”后刷新。原正则、角色表情、手帐风格和纸条存档继续使用。

```text
manifest.json
index.js
style.css
core.mjs
native-transport.mjs
README.md
```

旧Git仓库若保留了上一包的index.mjs、package.json，不影响前端扩展。本次发布包不需要这两个文件。没有额外npm依赖、付费解析账户、Cookie或图床设置。

## 自动推送

角色浏览记录提供站点与关键词→插件通过酒馆原生接口请求公开搜索和帖子→解析真实标题、作者、正文/摘要、配图→手帐直接展示。玩家不粘贴链接、不离开游戏搜帖。“再翻一条”自动重新匹配。

旧v2.0.1手帐的专用GET请求由兼容桥转入原生联网流程，桥只处理本插件同源的这一条地址。其他fetch、聊天API和发送框不受影响；禁用扩展会还原。普通网站文章的展示和明确故障提示需要同时更新配套notebook.json。

## 检查结果的含义

- “酒馆联网接口已连接”：酒馆具有可用的网页读取路由，可以提交读取任务。它不保证所有目标网站可访问。
- “当前酒馆没有可用的网页读取接口”：酒馆版本或部署没有提供此接口，需要更新酒馆；不要求去安装本项目旧的后台服务。
- “登录或请求校验未通过”：重新登录酒馆后刷新。插件通过酒馆公开getRequestHeaders取得请求校验头，不把它发到外站。
- “搜索来源要求验证”：本次公共搜索被限制。可以稍后重试，不会当作没有相关文章。
- “找到了链接但正文不可读”：目标站点需要登录或没有可读公开内容。能取得真实搜索摘要时会标注“搜索索引摘要”；否则保留对应占位。

手帐“翻找情况”会展示本次搜索、匹配、读取次数及错误类别，避免将连不上和没搜到混为一谈。普通“网页”不再只搜索几个社交站，也允许公开文章；明确站点仍严格匹配，不混到其他站点。

网站登录、反爬、索引覆盖、服务器外网条件和视频嵌入限制仍会影响结果。不会编造帖子、作者、全文或视频编号。

规范依据：[标准前端扩展](https://docs.sillytavern.app/for-contributors/writing-extensions/)、[酒馆原生网页读取接口源码](https://github.com/SillyTavern/SillyTavern/blob/release/src/endpoints/search.js)、[公开上下文请求头](https://github.com/SillyTavern/SillyTavern/blob/release/public/scripts/st-context.js)。
