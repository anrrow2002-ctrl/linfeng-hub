# 林锋手帐 · 自动推送 v2.1.0

给手帐自动翻找真实的公开内容。普通酒馆前端扩展，使用酒馆自带的 `/api/search/visit` 联网，不需要另装后台服务或修改 config.yaml。沿用已经确认的手帐画风、表情、纸条互动和原远程加载器。

## 玩家更新

插件仓库：https://github.com/anrrow2002-ctrl/linfeng-hub

- 已安装 v2.0.3 或更早版本：在酒馆「扩展」中找到这个插件，点击更新，再刷新整个酒馆页面。**这一步首次必须做一次**，因为旧版没有本次新增的更新检查代码；只刷新旧版或重启服务器不能代替 git 更新。
- 首次安装：在「扩展 → 安装扩展」粘贴仓库地址，安装后刷新。
- 更新后，设置面板应显示 v2.1.0。「检查联网接口」确认原生读取接口可用；它不代表每个外站都能访问。
- 手帐本体已是 v2.0.2 的，不用重新上传 notebook.json，不用更换酒馆助手加载器、正则或世界书。已有楼层保存的旧内容不会自动改写，点「再翻一条」才会重新联网。

## 这次修复

B站优先请求公开综合搜索接口，直接取得真实视频编号、标题、简介、作者和封面。详情页受限时仍能展示真实平台搜索摘要及播放器入口，不再先卡在 DuckDuckGo 验证页。支持 AV 编号、BV 编号和公开短链接。

其他来源继续按明确站点筛选，公共搜索并行尝试 Bing RSS、DuckDuckGo，失败或没有相关结果时使用搜狗与 Bing 网页作为后备。搜狗只取同一真实结果的可见标题、摘要与原站链接。普通文章可提取 article 中的公开正文。中文内容继续优先；成人站只用于记录明确指定该站的情况。

读取原帖失败时，若存在真实搜索摘要就显示「搜索索引摘要」，不把摘要说成全文、不让模型编造帖子。验证页、登录页和热门推荐不能冒充搜索结果。只有可用搜索确实没有相关条目时显示没有匹配；搜索全被拦、网络失败、正文受限会分别说明，手帐「翻找情况」保留具体来源与计数。

## 后续自动更新

新版启动后约 3 秒检查更新，持续打开页面时约每 30 分钟再检查一次。默认勾选「自动准备这个插件的更新，刷新后生效」，可以取消并改为手动检查、下载。

插件先通过酒馆原生扩展管理接口识别当前安装目录及个人/全局安装，并核对远端确实为本仓库；有更新时通过酒馆原生 git 更新接口下载。下载好后弹窗或提示一次，设置面板持续显示刷新按钮，玩家自己保存草稿并刷新即可使用。不强制刷新，不重启酒馆，不操作聊天发送框。

多名玩家共用同一个全局扩展时，由酒馆管理员更新；普通玩家权限不足会看到管理员提示。已经运行新版的其他玩家，会在下一次检查时发现服务器文件变新并收到刷新通知。独立部署的各个酒馆，在各自首次更新到本版后才能启用此机制。没有登录在线、禁用插件或运行旧版的客户端无法接收本模块通知。

若酒馆不支持原生扩展管理接口、仓库不可达或本地修改引起 git 更新失败，会显示具体更新状态并继续运行已有代码。可以从酒馆扩展管理页手动处理。

## 安装文件

仓库根目录包含以下 7 个文件，不要再套一层文件夹：

```text
manifest.json
index.js
style.css
core.mjs
native-transport.mjs
updater.mjs
README.md
```

旧仓库遗留的 index.mjs、package.json 不是本版运行依赖，不需要部署 Node 插件。浏览器只向自己的酒馆发送带会话校验的请求；会话头不传给外站。没有新增 Cookie、解析账户或图床配置。

## 可访问范围与验证

网站登录、验证码、地区限制、服务器网络以及播放器嵌入权限，仍由原站决定。本插件不会绕过登录或验证码，不能保证所有玩家在所有网络下看到任意网站全文或播放任意视频。即使标题和简介可读，播放器也可能另外限制地区、登录或嵌入。

本次在发布用 VPS 出口完整实测：B站、知乎、微博、Pornhub及普通网页样例均返回可展示的真实内容。B站通过综合搜索取得视频元数据，知乎通过真实搜索索引摘要，微博通过公开摘要；部分原站全文请求仍返回403、412或访客验证。B站播放器入口返回200，但没有把入口可读算作所有地区视频都能播放。需要稳定读取受限全文时，仍取决于可访问原站的酒馆网络出口或站点正式授权接口。

验证包括平台搜索及摘要回退、中文相关性、受限与真正空结果的区分，Chrome/WebKit 上的原生联网、界面展示，以及更新目录、仓库校验、权限、通知去重和不强制刷新。

规范依据：[酒馆原生读取](https://github.com/SillyTavern/SillyTavern/blob/release/src/endpoints/search.js)、[扩展发现与更新接口](https://github.com/SillyTavern/SillyTavern/blob/release/src/endpoints/extensions.js)。
